# Setup

Follow these steps in order. About 10 minutes, free.

## 1. Create a Supabase project

1. Go to supabase.com → **Start your project** → sign up (any email or GitHub).
2. Click **New project**. Name it anything, set a database password (you
   won't need it again for this), pick your region, click **Create new project**.
3. Wait about a minute while it sets up.

## 2. Create the database tables

1. Left sidebar → **SQL Editor** → **New query**.
2. Paste this in, then click **Run**:

```sql
create table tasks (
    id bigint generated by default as identity primary key,
    title text not null,
    team text not null,
    deadline timestamptz not null,
    needs_robot boolean not null default false,
    completed boolean not null default false,
    added_by text,
    created_at timestamptz not null default now()
);

create table events (
    id bigint generated by default as identity primary key,
    title text not null,
    datetime timestamptz not null,
    added_by text,
    created_at timestamptz not null default now()
);

alter table tasks enable row level security;
alter table events enable row level security;

create policy "public read" on tasks for select using (true);
create policy "public insert" on tasks for insert with check (true);
create policy "public update" on tasks for update using (true);
create policy "public delete" on tasks for delete using (true);

create policy "public read" on events for select using (true);
create policy "public insert" on events for insert with check (true);
create policy "public update" on events for update using (true);
create policy "public delete" on events for delete using (true);

alter publication supabase_realtime add table tasks;
alter publication supabase_realtime add table events;
```

3. You should see "Success. No rows returned."

## 3. Copy your keys into config.js

1. Left sidebar → gear icon (**Project Settings**) → **Data API**.
2. Copy the **Project URL** at the top of that page (looks like
   `https://xxxxxxxx.supabase.co`). Open `config.js` in this folder and
   paste it in:
   ```js
   const SUPABASE_URL = 'https://dhfnpglcmkykhaesiqrq.supabase.co';
   ```
3. Go to **Project Settings → API Keys**, copy the **Publishable key**
   (starts with `sb_publishable_...`) and paste it in:
   ```js
   const SUPABASE_ANON_KEY = 'sb_publishable_DpAYXiRBq9SYjvcjYanQDQ_leJzZ3jK';
   ```
   Never use the **Secret key** here — that one is private and must
   never go in this file.
4. Save `config.js`.

## 4. Put it online with GitHub Pages

1. Go to github.com, sign in (or sign up free).
2. Click **New repository** → name it anything → set it **Public** →
   **Create repository**.
3. On the empty repo page, click **"uploading an existing file"** and
   drag in every file from this `robotics-dashboard` folder → **Commit changes**.
4. Go to **Settings → Pages**. Under "Source" pick **Deploy from a
   branch**, branch `main`, folder `/ (root)` → **Save**.
5. Wait about a minute. GitHub gives you a link like
   `https://yourusername.github.io/robotics-dashboard/` — that's your
   team's shared board.

## 5. Open it on your phone

**iPhone (Safari):** open the link → tap the **Share** icon → **Add to
Home Screen**.

**Android (Chrome):** open the link, then tap the **⋮** menu (top
right). You'll see two different options — they are NOT the same:
- **Install** — the real app. Launches full-screen, no address bar,
  shows up as its own app on your phone.
- **Create shortcut** — just a bookmark. Always opens inside Chrome
  with the address bar, even though the icon looks the same.

Tap **Install**, not "Create shortcut."

**If "Install" says the app is already installed, but opening it fails
or does nothing:** Chrome's install record for the site got stuck (this
can happen after a failed first attempt). Fix it with a clean reset:
1. Chrome **⋮** menu → **Settings → Privacy and security → Clear
   browsing data**.
2. **Advanced** tab → time range **All time** → check **Cookies and
   site data** and **Cached images and files** → **Clear data**.
3. Fully close Chrome (swipe it away from your recent apps), reopen it.
4. Visit the link again → **⋮** menu → **Install**.

(Note: step 2 clears saved data for every site in Chrome, not just this
one — it's a blunt fix, but the reliable one when Chrome thinks an app
is installed and Android disagrees.)

---

**Security note:** anyone with the link can read, add, edit, or delete
anything on the board — there's no login. Fine for a low-stakes team
board; don't reuse this setup for anything you'd mind a stranger deleting.

**Updating later:** open the changed file on GitHub, click the pencil
(✏️) icon, paste in the new content, and commit. The live site updates
within a minute or two.
